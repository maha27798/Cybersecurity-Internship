

Weeks 5 & 6 – Ethical Hacking, Security Testing & Audits
📌 Project Title

Web Application Security Testing & Hardening using OWASP Juice Shop

📌 Environment Details

Operating System: Kali Linux

Test Application: OWASP Juice Shop

Deployment: Docker

Application URL: http://127.0.0.1:3000

🔐 WEEK 5: Ethical Hacking & Vulnerability Testing
🎯 Objective

To perform ethical hacking techniques on a test web application, identify common vulnerabilities, and verify the effectiveness of implemented security controls.

🛠 Tools Used

OWASP Juice Shop

Burp Suite

SQLMap

Kali Linux built-in tools

🔍 1. Reconnaissance & Traffic Analysis

Captured HTTP requests using Burp Suite

Analyzed GET and POST requests generated by user interactions

Identified authentication endpoints and API structure

Key Endpoint Tested:

POST /rest/user/login

💉 2. SQL Injection Testing
Test Method:

Manual SQL Injection payload testing

Automated testing using SQLMap on login endpoint

Payload Used:
' OR 1=1 --

Result:

Login attempt failed

Application returned Invalid email or password

SQLMap received HTTP 401 Unauthorized response

Conclusion:

The application is not vulnerable to SQL Injection attacks.
This indicates the use of secure coding practices such as:

Prepared statements

Input validation

Authentication enforcement

🛡️ 3. CSRF (Cross-Site Request Forgery) Testing
Test Method:

Captured login request in Burp Suite

Replayed request via Burp Repeater

Removed authentication cookies to simulate CSRF attack

Result:

Server rejected the request

Unauthorized / authentication error returned

Conclusion:

The application successfully prevents CSRF attacks by validating user session data and enforcing request integrity.

✅ Week-5 Summary

SQL Injection attempts blocked

CSRF attacks unsuccessful

No critical vulnerabilities identified

Application demonstrates strong backend security controls

Docker Security Practices

http://127.0.0.1:3000

No dangerous misconfigurations found

🧪 3. Lynis System Security Audit
Scope:

Host operating system security

Permissions, services, hardening level

Dependency security considered

🧠 OWASP Top 10 Compliance

The application demonstrates protection against:

Injection attacks

Security misconfigurations

🏁 FINAL CONCLUSION

This project successfully demonstrated ethical hacking techniques, vulnerability testing, and security auditing on a modern web application.
